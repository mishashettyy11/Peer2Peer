========================================================================
🚀 Mini P2P File Sharing System - Setup & Quickstart Guide
========================================================================

GitHub Repository: https://github.com/manjunathashetty548/Peer2peer


------------------------------------------------------------------------
STEP 1: Clone the Repository
------------------------------------------------------------------------
Open your terminal (PowerShell / Command Prompt / Terminal) and run:

    git clone https://github.com/manjunathashetty548/Peer2peer.git
    cd Peer2peer


------------------------------------------------------------------------
STEP 2: Install Python Dependencies
------------------------------------------------------------------------
On Windows:
    python -m venv venv
    .\venv\Scripts\activate
    pip install -r requirements.txt

On Mac / Linux:
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt


------------------------------------------------------------------------
STEP 3: Start the Tracker Server
------------------------------------------------------------------------
In Terminal 1, run:

    uvicorn tracker.main:app --reload --port 8000


------------------------------------------------------------------------
STEP 4: Start Peer Nodes
------------------------------------------------------------------------
In Terminal 2 (Peer 1):
    python -m peer.main --port 8001 --peer-id peer_1 --shared-dir shared_files

In Terminal 3 (Peer 2):
    python -m peer.main --port 8002 --peer-id peer_2 --shared-dir shared_files_2


------------------------------------------------------------------------
STEP 5: Start the React Visualization Dashboard (Optional)
------------------------------------------------------------------------
In Terminal 4:
    cd dashboard
    npm install
    npm run dev

Open browser at http://localhost:5173 to view active peers and chunk transfers!
